Evidencia C-05 (auth-sesion-roles): flujo manual con curl contra bootRun local (PostgreSQL de prueba, datos ficticios)
Fecha: 2026-11-21. Contraseña y valores de cookies enmascarados.

# 1. GET /api/v1/public/sesion (sin sesion; fija la cookie XSRF-TOKEN)
HTTP/1.1 200 
Set-Cookie: XSRF-TOKEN=<token>; Path=/
{"autenticado":false}

# 2. POST /api/v1/public/pacientes/registro (con token CSRF)
HTTP/1.1 201 
{"username":"evidencia.99000805@example.com","rol":"PACIENTE"}

# 3. POST /api/v1/public/login SIN encabezado CSRF -> 403 CSRF_INVALIDO
HTTP/1.1 403 
{"type":"about:blank","title":"Forbidden","status":403,"detail":"Token CSRF ausente o inválido","codigo":"CSRF_INVALIDO"}

# 4. POST /api/v1/public/login (con token CSRF; usuario en mayusculas)
HTTP/1.1 200 
Set-Cookie: JSESSIONID=***; Path=/; HttpOnly; SameSite=Lax
Set-Cookie: XSRF-TOKEN=<token>; Path=/
{"autenticado":true,"username":"evidencia.99000805@example.com","rol":"PACIENTE"}

# 5. GET /api/v1/paciente/perfil?pacienteId=1 (con sesion; el id del pedido se ignora)
HTTP/1.1 200 
{"nombre":"Paciente","apellido":"Evidencia","dni":"99000805","email":"evidencia.99000805@example.com","telefono":"1155550001"}

# 6. GET /api/v1/turnos con rol PACIENTE -> 403 ACCESO_DENEGADO
HTTP/1.1 403 
{"type":"about:blank","title":"Forbidden","status":403,"detail":"No tenés permiso para esta operación","codigo":"ACCESO_DENEGADO"}

# 7. POST /api/v1/logout
HTTP/1.1 204 
Set-Cookie: JSESSIONID=***; Max-Age=0; Expires=Thu, 01 Jan 1970 00:00:10 GMT; Path=/; SameSite=Lax
Set-Cookie: XSRF-TOKEN=<token>; Max-Age=0; Expires=Thu, 01 Jan 1970 00:00:10 GMT; Path=/

# 8. GET /api/v1/paciente/perfil sin sesion -> 401 NO_AUTENTICADO
HTTP/1.1 401 
{"type":"about:blank","title":"Unauthorized","status":401,"detail":"Hay que iniciar sesión","codigo":"NO_AUTENTICADO"}
