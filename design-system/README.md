# Design system: política visual del proyecto

Mode: off
Approval: skipped
Decisión: Sofia Indovino (líder), al aprobar el plan de fundación el 2026-11-18. Registrada el 2026-11-21.

## Qué significa

- El proyecto **no crea un design system ni mockups por change**.
- Motivo: la consigna no exige interfaz gráfica para el change OPSX (alcanza con una API o un módulo de dominio con tests), y el plazo es de 6 días.
- El frontend (TypeScript vanilla, responsivo) se construye sin una revisión visual previa. Los changes de UI registran `Decision: no (project policy)` en su `design.md`.

## Cómo cambiarlo

Solo la líder puede revisar esta política, a pedido explícito: invocar `/active-orchestrator design` y elegir `system-only` o `system-and-mockups`.
